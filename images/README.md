# 实拍图放这里

把你下载的 8 张图按下面的文件名放进这个文件夹，再把 `index.html` 里的 `<div class="dish-emoji">` 换成 `<img class="dish-photo">`。

| 文件名 | 对应菜品 | 建议画面 |
| --- | --- | --- |
| `roujiamo.jpg` | 肉夹馍 | 白吉馍夹肉，横切面能看到肉 |
| `yangrou-paomo.jpg` | 羊肉泡馍 | 一碗泡馍 + 糖蒜 |
| `biangbiang.jpg` | biangbiang 面 | 宽面 + 油泼辣子 |
| `saozi-mian.jpg` | 岐山臊子面 | 红汤、五色配菜 |
| `liangpi.jpg` | 凉皮 | 拌好的凉皮，红油明显 |
| `hulutou.jpg` | 葫芦头泡馍 | 一碗浓汤泡馍 |
| `zenggao.jpg` | 甑糕 | 切块，能看到枣和豆 |
| `shizibing.jpg` | 黄桂柿子饼 | 金黄小饼堆在一起 |

要求：

- 格式 `.jpg` 或 `.webp`，**宽 800px 左右**就够，单张别超过 300KB（不然仓库会很大）。
- 比例最好是 **4:3**，页面会按 `object-fit: cover` 自动裁切，不会被拉变形。
- 版权：用你自己拍的，或明确标注可免费商用的图库（如 Pexels / Unsplash）的图；**不要用小红书、视觉中国、花瓣上的图**。

没放图也不影响页面显示，现在用的是 emoji + 色块占位。
